7. Comments to the author(s)

This manuscript presents an open-source dashboard for exploring the AI-READI

multimodal diabetes dataset.

- the contribution is largely an engineering system rather than a research advance.

- most components build upon existing technologies (FastAPI, React, REST APIs,
standard visualization libraries) with limited methodological novelty.
- it would be strengthened by including quantitative comparisons with existing tools (e.g.,
Jupyter notebooks or OHDSI ATLAS), usability studies involving target users,

measurements of time savings across multiple tasks, scalability experiments, or feedback
from clinical researchers.
- discussing software maintainability, extensibility, and deployment in larger institutional
environments would further improve it.

Overall, this is a software contribution without research novelty.

7. Comments to the author(s)
This paper presents an AI-READI Explorer, an open-source platform for clinical data
analytics to reduce the barriers to data readiness in multimodal studies of Type 2
Diabetics. It includes three EDA tools that turn modality coexistence, temporal
synchronization, and signal integrity into a 15-minute handson process and finds
significant outcomes. It is an interesting tool assisting clinical prediction. It needs the
following issues to be addressed to get it published:
1. Novelty – this paper is a GUI based implementation. Though the authors claim it is the

first dedicated dashboard for analyzing the AI-READI dataset but it does not contain any
unique research contribution.
2. Implementation – should be specific
3. Validity – it is missing
4. Figures – requires more clear and readable pictures
5. Referencing – inadequate references and should be in sequence in the body
